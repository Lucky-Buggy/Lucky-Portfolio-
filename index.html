Buka-Bus — Bus Booking System

The Challenge

Bus terminals were doing everything by hand. Passengers had to line up at counters. Staff wrote down seat availability on paper or used basic spreadsheets. Tickets were handwritten. This created a lot of problems. Buses got overbooked. Queues got really long. There was no way to track what actually happened.

The Solution

Buka-Bus takes the whole booking process online. Passengers can see available trips, pick their own seats, and get a confirmed booking right away. No more standing in line. No more paperwork. Staff doesn't have to do the work manually anymore.

Key Features

  • Interactive seat selection map with real-time availability
  • Automated generation of unique booking reference tickets
  • Trip and schedule management for administrators

My Technical Role

I built the database that keeps everything organized. I made sure trips, seats, bookings, and passenger info all connect properly without any mix-ups. Then I wrote the code in PHP that handles the actual booking. This includes making sure two people can't book the same seat at the same time, and creating the ticket reference number when a booking is complete.
